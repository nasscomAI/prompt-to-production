# Enforcement Rules
1. Exact strings only for categories: Pothole, Flooding, Streetlight, Waste, Noise, Road Damage, Heritage Damage, Heat Hazard, Drain Blockage, Other. No variations.
2. Priority is Urgent if severity keywords present: injury, child, school, hospital, ambulance, fire, hazard, fell, collapse. Otherwise Standard.
3. Reason must be exactly one sentence and cite specific words from the description.
4. Flag as NEEDS_REVIEW if the category is genuinely ambiguous.
