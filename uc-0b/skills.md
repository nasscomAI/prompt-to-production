name: retrieve_policy
description: >
  - Loads a local raw .txt policy document and parses its content into clean, distinct blocks mapped explicitly to their original clause numbers.
input: >
  - file_path: A string representing the relative path to the policy text file (e.g., "../data/policy-documents/policy_hr_leave.txt").
output: >
  - structured_clauses: A structured list or array where each item contains a string identifier for the clause (e.g., "2.3") and the exact raw text of that clause.
error_handling: >
  - If the file path is invalid or missing, raise a FileNotFoundError.
  - If the file is empty or corrupted, raise a ValueError indicating the file contents cannot be parsed.

name: summarize_policy
description: > 
  Core summarization engine that processes structured clauses. It condenses text while strictly enforcing meaning preservation, keeping all multi-condition approvals intact, and maintaining strict binding verbs.
input: >
  - structured_clauses: The list of clause objects generated by the retrieve_policy skill.
output: >
  - compliant_summary: A dense, clause-by-clause summary text document mapping every single rule back to its original clause number with zero meaning modification.
error_handling: >
  - If any input clause is dropped or omitted during processing, abort execution and raise an OmissionValidationError.
  - If a multi-condition rule is condensed down to a single condition (e.g., dropping an authorizer), halt and raise a ConditionDropException.
  - If any binding verb (must/will/requires) is replaced by a soft verb (should/expected), raise an ObligationSofteningException.
