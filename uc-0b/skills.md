# Skills

## retrieve_policy

Input:

* Policy text file

Output:

* Structured numbered clauses

Responsibilities:

* Read the text file.
* Preserve clause numbers.
* Return structured sections.

---

## summarize_policy

Input:

* Structured policy clauses

Output:

* Summary with clause references

Rules:

* Every clause must appear.
* Preserve mandatory wording.
* Preserve all conditions.
* Quote clauses verbatim when necessary.
