- `retrieve_policy`:
  - Input: Path to a `.txt` policy file.
  - Action: Loads the text file and returns the content as structured numbered sections to facilitate parsing and summarization.
- `summarize_policy`:
  - Input: Structured policy sections.
  - Action: Applies the summarization enforcement rules to produce a compliant summary with clause references. Ensures no critical condition is dropped and no hallucination occurs.
  - Output: Returns the final summary string to be written to a file.
