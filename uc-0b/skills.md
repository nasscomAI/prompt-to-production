# skills.md

skills: - name: retrieve_policy description: \> Loads the HR leave
policy from a text file and converts it into structured numbered
sections while preserving clause numbers and original ordering.

    input:
      type: text_file
      format: UTF-8 plain text (.txt)

    output:
      type: structured_document
      format: >
        List of numbered clauses with section headings and clause text.

    error_handling: >
      If the file cannot be found, is empty, or is unreadable,
      return an error explaining the problem and stop processing.
      Never attempt to guess or reconstruct missing policy content.

-   name: summarize_policy description: \> Produces a concise summary of
    the HR leave policy while preserving every mandatory obligation,
    approval requirement, deadline, exception, and prohibition.

    input: type: structured_document format: \> Numbered policy clauses
    generated by retrieve_policy.

    output: type: text format: \> Human-readable summary with clause
    references that preserves the meaning of the original document.

    error_handling: \> If any clause cannot be summarized without
    changing its meaning, include the original clause verbatim and flag
    it for manual review. Never omit clauses, invent information, weaken
    mandatory language, or merge multiple conditions into a simplified
    statement.
