skills:
  - name: retrieve_policy
    description: >
      Technical Data Ingestion Pipeline: Loads the unstructured .txt policy document, applying text-parsing routines to extract content.
      Business Objective: Ensure the raw policy elements are isolated accurately for subsequent rigorous validation.
    input: 
      type: string
      format: filepath
      description: The path to the textual HR policy source (e.g., `policy_hr_leave.txt`).
    output: 
      type: array of objects
      description: Tokenized/structured data representation containing numbered sequence indices and their corresponding verbatim policy text.
    error_handling: 
      - Trigger FileNotFound or AccessDenied errors with stack details if the policy document is absent.
      - Log structural integrity warnings and flag clauses that fail to align with the expected numbered taxonomy.

  - name: summarize_policy
    description: >
      Technical Summarization Engine: Transmutes structured policy arrays into a compressed human-readable text payload.
      Business Objective: Produce a summary with 100% adherence to legal/HR obligations. Never soften strict bindings (e.g. 'requires' or 'must'), never assume missing norms, and ensure multi-approver stipulations are wholly retained.
    input: 
      type: array of objects
      description: The canonical structured clause inventory generated by the `retrieve_policy` skill.
    output: 
      type: string
      format: markdown/text
      description: A compliant, scope-restricted summary cross-referencing exact clause numbers, free of external 'scope bleed'.
    error_handling: 
      - Raise an exception and abort summarization if the input array is malformed, missing core fields, or empty.
      - Execute Defensive Fallback: If a clause's complexity prevents summarization without meaning loss, emit the clause verbatim wrapped in alert markers (e.g., [FLAGGED: Meaning Preservation Limit]).
