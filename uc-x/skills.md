# UC-X Ask My Documents Skills

## Skill 1: Load Documents
Read the provided policy documents separately.
Identify each document by its filename or title.

## Skill 2: Select Relevant Document
Determine which document is relevant to the question.
Do not combine information from different documents unless the question explicitly asks for a comparison.

## Skill 3: Answer From Source
Answer only from information found in the provided documents.
Do not use outside knowledge or assumptions.

## Skill 4: Preserve Conditions
Preserve important:
- conditions
- exceptions
- requirements
- limits
- approval rules
- dates and deadlines

Never remove a condition that changes the meaning.

## Skill 5: Handle Missing Information
If the answer cannot be found in the documents, state:
"Information not found in the provided documents."

Never guess or invent an answer.

## Skill 6: Cross-Document Questions
If the question asks about multiple documents, clearly separate the answer by document and identify the source.

## Skill 7: Validation
Before answering, verify that:
- The correct document was identified.
- The answer comes only from the provided documents.
- Documents were not incorrectly blended.
- No information was invented.
- Important conditions and requirements were preserved.
