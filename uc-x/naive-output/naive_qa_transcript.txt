# Carrying Forward Unused Annual Leave

Yes, you can carry forward unused annual leave, but there are important limitations:

**Maximum Carry-Forward:**
- You may carry forward a **maximum of 5 unused annual leave days** to the following calendar year
- Any days above 5 are **forfeited on 31 December**

**Timeline for Using Carry-Forward Days:**
- Carry-forward days must be used within the **first quarter (January–March)** of the following year
- If not used by the end of March, they are **forfeited**

So in summary, you can carry forward up to 5 days, but you must use them within the first three months of the next year or lose them.

# Installation of Slack on Work Laptop

According to the IT Acceptable Use Policy (IT-POL-003, Section 2.3-2.4):

**You cannot install Slack on your work laptop without written approval from the IT Department.**

The policy states:
- **Section 2.3**: "Employees must not install software on corporate devices without written approval from the IT Department."
- **Section 2.4**: "Software approved for installation must be sourced from the CMC-approved software catalogue only."

**To install Slack, you must:**
1. Request written approval from the IT Department
2. Confirm that Slack is available in the CMC-approved software catalogue

If you proceed without approval, you may face disciplinary action.

Based on the IT Acceptable Use Policy, **no, you cannot use your personal phone to access work files when working from home**.

Here's why:

According to section 3.1 of the IT Acceptable Use Policy, personal devices may be used to access **only**:
- CMC email
- CMC employee self-service portal

Section 3.2 explicitly states that personal devices must **not** be used to access, store, or transmit classified or sensitive CMC data.

Work files would fall outside the limited permitted uses for personal devices. If you need to access work files while working from home, you should use a corporate device provided by CMC instead.
